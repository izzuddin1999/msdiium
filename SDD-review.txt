P38 [Heading 1]: INTRODUCTION
P40 [Normal]: Software Design Description (SDD) is a representation or model of IIUM Staff Promotion System. It provides the precise design information needed for planning, analysis, and implementation of the system. It represents a partitioning of the system into design entities and describes the important properties and relationships among those entities. It includes the document purposes, system scopes, definitions, acronyms, abbreviations, references, and overview of the SDD document.
P41 [Heading 2]: Purpose(s)
P43 [Normal]: The purpose of this document is to shows how the system will be structured to satisfy the requirements identified in the SRS. It is a translation of requirements into a description of the software structure, software components, interfaces, and data necessary for the implementation phase. The design description is used to represent a system that can be expressed as a collection of design entities, each possessing properties and relationships. To simplify the model, the properties and relationships of each design entity are described by a standard set of attributes. A design description is complete when the attributes have been specified for all the entities. In a complete SDD, each requirement must be traceable to one or more design entities. In essence, the SDD becomes a detailed blueprint for the implementation activity.
